Vibey

Overview

Goal

Vibey exists to kill the blank-page problem before a build even starts. When you want to prototype something fun but don’t have a concept yet, Vibey gives you one instantly.

Solution

A single-page “roll the dice” generator: hit reroll and Vibey surfaces a portfolio-worthy product concept — complete with a name, a one-line pitch, and a copy-paste-ready Claude Code starter prompt — so the gap between idea and first build collapses to one click.

Role

Design & Build (Solo)

Type

Personal tool — vibe-coded

Stack

Claude Code, HTML/CSS/JS

Status

Live

Live Demo

Impact

Vibey now seeds new weekend builds on demand — this very case-study template, and the “Vibe Coded” tab it lives under, both started as a Vibey roll.
